# Портфолио — сайт-визитка

Статичный сайт (HTML/CSS/JS, без сборки), хостится на GitHub Pages.

## Как править

- **Тексты, имя, названия работ** — `assets/js/content.js` (словарь `I18N` для RU / DE / EN и список `WORKS`).
- **Контакты** — блок `CONTACT` в `index.html` (почта и ссылки на соцсети).
- **Фото** — в `index.html`, блок `about__frame`: заменить заглушку на `<img src="assets/img/me.webp" alt="...">`.
- **Новая работа** — положить `assets/img/<id>.webp` (~1600px) и `<id>-sm.webp` (~720px), добавить строку в `WORKS`.

Все места с заглушками помечены `[Заглушка]`, `Имя`, `Фамилия`, `hello@example.com`, `href="#"`.

## Локальный просмотр

```sh
python3 -m http.server 8000
# открыть http://localhost:8000
```

Картинки временно вырезаны из PDF-портфолио; когда будут оригиналы — просто заменить файлы с теми же именами.
